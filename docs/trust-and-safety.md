# Trust and Safety

**Status:** Beta
**Last updated:** 3 November 2026

---

## Intended use

Premedice is an evidence-first medical information and decision-support assistant for patients, caregivers and clinicians.

## Emergency and crisis

Premedice is not for emergency care. Chest pain, stroke symptoms, severe bleeding, anaphylaxis, breathing difficulty, loss of consciousness, or suicidal thoughts require local emergency services or a crisis line immediately.

## Evidence

Premedice returns sources with its answers. Sources should be read and checked against the patient's full context. A cited answer is a starting point for review, not a substitute for clinical judgment.

## Doctor sharing

Doctor access is patient-controlled, scoped and revocable. Access is logged. Sharing a record is not a clinical endorsement.

## Data safety

- Do not submit PHI without an appropriate agreement.
- Do not put patient data in GitHub issues, pull requests or discussions.
- Report a vulnerability through GitHub private vulnerability reporting; see [SECURITY.md](../SECURITY.md).

## Reporting a problem

For a product safety issue, include the request type, the answer, whether a source was wrong, and a redacted example. Do not include patient identifiers.
