# Premedice — Roadmap

**Status:** Beta
**Last updated:** 3 November 2026

This roadmap describes direction, not delivery promises. Dates are intentionally omitted.

---

## Now

- [x] Whole-record chat with care contexts
- [x] Lab memory v1: parsing, units, trends, chart
- [x] Evidence capture and citation chips
- [x] Post-answer evidence check
- [x] Medicine cards and drug-label evidence
- [x] ClinPGx, rare-disease, and AlphaFold tools
- [x] Doctor links, roster, patient notes, access log
- [x] Health briefs: generation, UI, manual email
- [x] OpenAI-compatible API and MCP
- [x] Icon pack, PWA manifest, social preview

## Next

- [ ] Published clinical evaluation
- [ ] Critical red flags that change the main answer
- [ ] Lab coverage: 150 analytes, real formats, backfill, dedup, manual correction
- [ ] Health brief automatic send and unsubscribe
- [ ] Doctor OTP/domain verification and signed review
- [ ] Family member invite and permissions
- [ ] Public latency and reliability reporting
- [ ] Model ID consistency across app, API, and docs

## Later

- [ ] Country-specific lab ranges
- [ ] Spanish, Portuguese, Arabic, French, and German support
- [ ] Care plan and cost navigator
- [ ] FHIR export
- [ ] Trial eligibility matching
- [ ] CPIC rule engine and optional genomic upload
- [ ] Prospective outcome study

## Not planned

- a foundation model trained from scratch
- autonomous diagnosis
- autonomous prescribing
- emergency triage
- a full EHR
- wearables in the first clinical release
